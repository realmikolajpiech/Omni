I will optimize the memory usage by consolidating the models and implementing an idle unload mechanism.

### 1. Consolidate Models (Save ~2.5GB)
- Currently, the app loads a separate "Fast Model" (Qwen3-0.6B) in the Python process using `transformers`, which consumes ~2.5GB RAM.
- I will modify `model_manager.py` to remove this separate model and instead use the "Main Model" (Qwen3-VL-4B) for all tasks. The Main Model is already loaded in the `llama-server` process, so this immediately frees up the Python process memory.

### 2. Optimize Main Model Server (Save ~2GB)
- The `llama-server` is running with an 8192 context window (`-c 8192`), which consumes significant RAM.
- I will modify `start_model_server.sh` to reduce the context to **4096** tokens, which is sufficient for most tasks and will reduce the server's memory footprint.

### 3. Implement Auto-Unload (Save ~6GB when idle)
- I will implement an **Auto-Unloader** in `model_manager.py`.
- If the LLM is not used for **5 minutes**, the `llama-server` process will be terminated and the Python resources released.
- The model will automatically reload (taking 2-3 seconds) when you next interact with it.

This approach will bring idle memory usage to near zero (just the GUI overhead) and significantly reduce active memory usage.
