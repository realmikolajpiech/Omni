I will fix the "double server" bug which is causing the extra 1.25GB memory usage.

### **Why are there 2 servers?**
It is a bug (race condition). When the app starts, two parts of the system are trying to wake up the "Brain" at the exact same time. They both succeed in launching a server before checking if one is already running. You definitely **do not** need both.

### **Plan: Fix Race Condition & Single Instance Enforcement**

1.  **Modify `src/services/llm/model_manager.py`**:
    *   Move the server startup logic inside a **thread-safe lock**. This ensures only one startup attempt can happen at a time.
    *   **Add "Liveness" Check**: Before starting a new server, the code will:
        1.  Check if a PID file exists (`~/.config/omni/qwen_server.pid`).
        2.  Check if that specific process ID is actually running.
        3.  Check if the port (8081) is already in use.
    *   **Reuse**: If a server is already found running, the app will simply connect to it instead of spawning a new one.

2.  **Outcome**:
    *   Only **one** `llama-server` process will run.
    *   **Memory Savings**: Immediately saves ~1.25 GB of RAM.
    *   **Stability**: Prevents port conflicts and "address already in use" errors.
