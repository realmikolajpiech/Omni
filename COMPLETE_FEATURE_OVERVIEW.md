## 🎓 Tips for Best Experience

### Pro Tips

1. **Use Partial Names**: "req" finds "requirements.txt"
2. **Arrow Navigation**: Smooth keyboard workflow
3. **Preview First**: Use CTRL+S to verify file
4. **CWD Focus**: Searches nearby first
5. **Combine Keys**: Type quickly, then arrows, then preview

### Best Practices

1. Search specific names for better results
2. Use CTRL+S before ENTER to verify
3. Use arrow keys for smooth navigation
4. ESC to exit and try new search

### Performance Tips

1. Run from project folder for best results
2. Shorter search terms = faster (fuzzy not supported)
3. Exact matches ranked highest
4. Results cached for repeated searches
